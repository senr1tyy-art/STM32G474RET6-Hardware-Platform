# GJH-Board V1.0
## 1. 项目简介
GJH-Board V1.0 是一款基于 STM32G474RET6设计的四层通用硬件开发平台。
本人独立完成原理图设计、元器件选型、PCB Layout、BOM 整理、实物焊接及基础硬件调试。

## 2. 项目参数
- MCU：STM32G474RET6
- PCB 层数：4 层
- PCB 尺寸：100 mm × 100 mm
- PCB 设计工具：Altium Designer 24
- 固件开发工具：Keil MDK
- 下载调试工具：ST-Link
- 硬件调试工具：数字万用表

## 3. 硬件功能
- USB Type-C 供电接口
- 5V 输入及 3.3V LDO 稳压
- MCU 核心电路
- SWD 调试接口
- ADC 模拟输入
- SPI Flash 存储接口
- RS485 通信接口
- CAN 通信接口
- LED 状态指示
